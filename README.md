# سوق المواشي اليمني — تطبيق أندرويد (MVP)

## حالة المشروع
- ✅ الواجهات: الرئيسية (تصفح/بحث/فلترة)، تفاصيل الإعلان، نشر إعلان، إعلاناتي
- ✅ التنقل بين الشاشات (Bottom Navigation)
- ✅ التواصل عبر واتساب من صفحة التفاصيل
- ✅ أيقونة التطبيق مُدمجة بكل الأحجام المطلوبة
- ✅ بيانات تجريبية (Mock) تعمل بدون أي إعداد خارجي — التطبيق يبني ويعمل فورًا
- ⏳ Firebase Firestore + Storage (الصور الحقيقية وتخزين الإعلانات) — الخطوة القادمة، سنعملها معًا خطوة بخطوة
- ⏳ تسجيل الدخول (Firebase Auth) — لاحقًا مع Firebase

## كيف ترفعه من ترمكس إلى GitHub

1. فك ضغط الملف في مجلد على جهازك:
```
unzip SouqAlMawashi.zip
cd SouqAlMawashi
```

2. تهيئة git ورفع المشروع لمستودع جديد (استبدل الرابط برابط مستودعك):
```
git init
git add .
git commit -m "أول نسخة MVP - سوق المواشي اليمني"
git branch -M main
git remote add origin https://github.com/abuhamam2015929-netizen/SouqAlMawashi.git
git push -u origin main
```

3. بمجرد الرفع، GitHub Actions سيبني ملف APK تلقائيًا (بدون الحاجة لأي gradlew أو ملفات binary — الإعداد يعتمد على Gradle السحابي مباشرة).

4. لتنزيل الـ APK الناتج: افتح تبويب **Actions** في المستودع → افتح آخر تشغيل ناجح → حمّل الملف من قسم **Artifacts** باسم `souq-al-mawashi-debug`.

## الخطوة القادمة
عندما تكون جاهزًا، ننشئ حساب Firebase ونربط:
- Firestore (لتخزين الإعلانات الحقيقية بدل البيانات التجريبية)
- Storage (لرفع صور الحيوانات الفعلية)
- Auth (تسجيل الدخول برقم الجوال)

هيكل الكود جاهز مسبقًا لهذا الانتقال (`ListingRepository` قابل للاستبدال دون تعديل أي شاشة).
